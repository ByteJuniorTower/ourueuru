# Mushroom Guardians – Lobby props (Guardians' Glade)

Procedural low-poly props generated by one deterministic script (seeded RNG, flat colours, emission for glowing parts).

## Files
- `build_lobby_props.py` – builds all props (constants at top, one function per prop), exports GLBs, renders previews, saves the .blend.
- `lobby_props.blend` – saved Blender project, all props laid out side by side along +X (generated by the script; exports are made with each prop at the origin before layout).
- `export/<Name>.glb` – one GLB per prop (+ 7 `Build_Lobby_MapStone_<Region>.glb`), glTF default +Y up (Blender Z up converts to this).
- `preview/<Name>.png` – 512×512 transparent Cycles-CPU renders (12 samples).

## Regenerate
```
uv venv --python 3.11 /tmp/bpyenv && uv pip install --python /tmp/bpyenv/bin/python bpy
/tmp/bpyenv/bin/python build_lobby_props.py        # or: blender -b -P build_lobby_props.py
```
Built and tested with `bpy` 5.0.1 (Blender 5.0, pip wheel, Python 3.11). Set `RENDER_PREVIEWS = False` to skip renders.

## Conventions
1 Blender unit = 1 stud (character ≈ 5 studs). Origin at the ground (z = 0) at the prop's centre/base, front faces −Y. Each prop is one collection with an Empty root at the origin; mesh objects are parented to it with transforms applied. Materials are Principled flat colours (emission strength 4–6 for glow). Meshes are flat-shaded except sphere blobs (caps, moss).

Triangle counts above are from the exported GLBs (checked with trimesh; the script prints n-gon-fan counts that are equal or slightly higher). All exports re-load with trimesh, contain only the prop (no camera/light/cube), and have min height 0 (±0.01 on SporeLantern and NoticeBoard from tilted posts).

## Known limitations / honest notes
- FairyRing is ~3.3k tris, slightly above the ~3k budget.
- Several props are slightly larger than the requested footprints (see table); scale in Studio if needed.
- Workbench/EEVEE previews crash headless (no libEGL), so previews use Cycles CPU with a plain sun light; they are not Roblox lighting.
- No UVs/image textures (by design); colours are flat per-material. Roblox MeshPart import takes geometry only, so apply colours via `Color`/SurfaceAppearance or import with the GLB materials.
- Statue sickle blade is a segmented arc without tapering; the statue face is minimal.
- Visual check was done on preview renders only; none of the props were imported into Roblox Studio here.
